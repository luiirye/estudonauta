# Exercícios

Os desafios deste mundo usam a numeração oficial própria, iniciada no exercício 016.

- Um arquivo: `exercicio_016.py`.
- Vários módulos: `exercicio_021/main.py` e seus módulos auxiliares.

Ao concluir um exercício, acrescente-o ao [índice geral](../../../docs/INDICE_EXERCICIOS.md#mundo-04--orientação-a-objetos).
